# Problem 3 : 종합해양과학기지 유의파고 단기 예측 (https://oceanaidata.org/app/problems/7)
3-1. 배경
유의파고는 항해 안전, 해상 공사, 연안 시설 관리의 핵심 기준입니다. 지점 관측 이력을 학습하면 수치파랑모델 없이도 단기적인 풍파의 발달·감쇠 특성을 분석할 수 있습니다. 다만 미래 기상장과 원격 해역 정보가 없으므로 리드타임이 길어질수록 예측력에 한계가 있으며, +18시간과 +24시간은 의도적으로 도전적인 구간입니다.

3-2. 과제
각 익명 평가 사례(case_id)에 포함된 과거 48시간 관측만 사용하여 3·6·9·12·18·24시간 뒤 유의파고를 예측하십시오.

구분	내용
대상	G-ORS · I-ORS · S-ORS
학습기간	2024-01-01~2025-06-30
평가기간	2025-07-04~2026-06-30
사례 선정	기준시각 hs≥1.5m, 6개 리드 정답이 모두 유효한 사례
독립 사례	200개(동일 정점 내 기준시각 최소 78시간 간격)
리드타임	+3h · +6h · +9h · +12h · +18h · +24h
리드별 건수	각 200건
총 채점	1,200건
지표	통합 RMSE(m)
3-3. 변수
변수	단위	설명
hs	m	유의파고, 상위 1/3 파고 평균
tp	s	상위 1/3 파의 평균 주기, 첨두주기 아님
hmax	m	구간 최대파고
wvdir	deg	파가 오는 방향, 진북 기준 시계방향

airt, relh	℃, %	기온, 상대습도
파랑은 20분, 기상은 10분 간격입니다. 컨텍스트는 10분 격자의 상대시간 step_minute=-2880,-2870,...,0이며 파랑이 없는 중간 10분 행은 파랑 열이 결측입니다.

3-4. 미래정보 차단 구조
test_context.parquet는 각 case_id의 기준시각 이전 48시간만 포함하며 절대 평가시각은 공개하지 않습니다.
동일 정점의 사례 기준시각은 최소 78시간 간격입니다. 컨텍스트 48시간 + 타깃 24시간 + 완충 6시간으로, 어떤 사례의 컨텍스트도 다른 사례의 타깃 구간과 겹치지 않습니다.
사례 컨텍스트 구간은 학습 파일(2025-06-30 종료) 기간과도 겹치지 않습니다. 사례를 절대시각에 대응시킬 단서가 배포본에 없습니다.
현재 예측에는 반드시 동일한 case_id 그룹만 사용해야 합니다.
case_id와 실제 기준시각의 대응표는 운영자 전용으로 분리되어 있습니다.
