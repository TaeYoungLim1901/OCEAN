# 작업 지시: T15 — 보존 풀 잔차 상관 측정 + 동일가중 다양성 블렌드

루트 `AGENTS.md` 와 `P3/AGENTS.md` 준수. python 은 시스템 `python` 을 쓴다.
`pip install` 이 필요하면 **멈추고 보고하라**. `P3/P3_data/` 와 `P3/src/metric.py` 는 읽기 전용.

**학습·모델 재적합 금지. 저장된 예측만 읽는다. `n_jobs` 는 2 로 고정.**

## 배경 — 이미 검증된 사실 (재조사 금지)

```
f.thinned_judge_inverts  씨닝 봉인 53사례는 damped/lgbm 순위조차 뒤집는다
f.dense_judge_bias       조밀 재가중으로 편향 제거 (T9, ESS fold4 649.3)
f.hp_below_noise_floor   T13: LGBM 6후보의 folds1-3 순위 vs 봉인 fold4 순위 Spearman -0.83.
                         fold4 범위 0.016 / fold2·3 범위 0.005. fold1 분산이 선택을 지배한다
f.t1f_weights            현행 제출 T1F = persistence 0.00 / damped 0.35 / lgbm_t1 0.65
```

`f.hp_below_noise_floor` 때문에 **가중을 로컬에서 적합하면 반대로 고른다.**
그래서 이번엔 가중을 적합하지 않는다. 동일가중만 쓴다. 선택 분산이 0 이어야 한다.

기준 점수 (재계산 금지): 조밀 재가중 봉인 fold4 에서 T1F `0.611959`, `lgbm_t1` `0.614009`,
`damped` `0.663402`, `persistence` `0.769115`.
fold 별 ESS = fold1 `571.931657` / fold2 `948.602515` / fold3 `1124.684355` / fold4 `649.308480`

## 기준선 — 사용할 자산

```
P3/cache/p3_t8/dense_index.csv      # case_id, station, fold, hs0  (조밀 5963건, folds1-4)
P3/cache/p3_t9/dense_weights.csv    # case_id, stratum, w — 재생성 금지
P3/preds/oof_*.npy , P3/preds/test_*.npy
```

**재가중 RMSE 정의는 T9·T11·T13 과 동일:** `sqrt(Σ w_i (y-p)² / Σ w_i)`, 리드 동일 가중.
fold 경계·층 정의·재가중을 다시 만들지 마라.

## 작업 0 — 풀 인벤토리

`P3/preds/` 의 모든 `oof_*.npy` 와 `test_*.npy` 를 열어 표로 낸다:
파일명 / 형상 / NaN 수 / **어느 인덱스에 정렬되는가** (조밀 5963 / 씨닝 / test 200 / 불명).

조밀 인덱스에 정렬되는 OOF 만이 조밀 판정기로 채점 가능하다.
불명인 파일은 **추측하지 말고 "불명"으로 보고**하고 이후 작업에서 제외한다.

## 작업 1 — 잔차 상관 행렬 (조밀 뷰)

조밀 인덱스에 정렬된 OOF 멤버 전부에 대해 잔차 `r = y - pred` 를 만들고,
`dense_weights.csv` 의 `w` 로 **가중 Pearson 상관**을 계산한다.

- 봉인 `fold4` 와 `folds1-3` 두 구간을 따로 낸다
- 리드는 합쳐서 사례×리드 를 하나의 벡터로 편다
- 대각 제외 상관 **최저 10쌍**을 값과 함께 보고
- 각 멤버의 `lgbm_t1` 대비 상관을 **전부** 보고 (이게 작업 3 의 입력이다)

## 작업 2 — 잔차 상관 행렬 (씨닝 뷰, 진단용)

조밀 OOF 가 없는 멤버(T2 5후보·eqrelax 등)는 씨닝 뷰에서만 잴 수 있다.
씨닝 뷰에서 동일하게 비가중 잔차 상관을 내고, `lgbm_t1` 대비 상관 최저 5개를 보고한다.
**이 표는 진단용이다. 작업 3 의 선택 근거로 쓰지 마라.**

## 작업 3 — 동일가중 다양성 블렌드 (사전등록)

조밀 뷰에서 `lgbm_t1` 과의 **`folds1-3` 잔차 상관이 `0.90` 미만**인 멤버를 전부 고른다.
`fold4` 상관은 선택에 쓰지 마라 (봉인).

그 멤버들 + `lgbm_t1` 을 **동일가중 산술평균**한다. **가중을 탐색하거나 조정하지 마라.**
멤버가 0개면 그 사실만 보고하고 블렌드를 만들지 마라.

- OOF 블렌드를 조밀 재가중 `folds1-3` 과 봉인 `fold4` 로 각각 채점
- 대응 `test_*.npy` 를 같은 동일가중으로 평균해 `P3/preds/test_div_p3_t15.npy` 저장
- OOF 는 `P3/preds/oof_div_p3_t15.npy`
- **제출 CSV 는 만들지 마라**

### 수락 기준 (결과 보기 전 고정)

- 상관 행렬이 대칭이고 대각이 `1.0 ± 1e-9`
- 선택에 `fold4` 가 쓰이지 않았다 (코드로 보장. 방법을 한 줄로 보고)
- 동일가중 계수가 전부 `1/k` 로 정확히 같다
- **채택 조건**: 봉인 `fold4` 조밀 재가중 점수가 T1F `0.611959` 를 `0.005` 이상 개선.
  미달이면 기각하되 OOF/test 는 풀에 남긴다
