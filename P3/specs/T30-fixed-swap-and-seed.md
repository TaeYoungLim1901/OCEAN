## 배경 · 기준선(baseline) 숫자 — 재조사 금지, 그대로 쓴다

판정기는 **조밀 재가중** 하나뿐 (`f.lb_picks_dense_judge`). 채점 경로는 `P3/src/run_t21.py`
가 쓰는 것을 그대로 import 해서 재사용한다.

| 조밀 재가중 봉인 fold4 | RMSE |
|---|---|
| 현행 T1F (= W_old 블렌드) | 0.611959 |
| `lr` 단독 | 0.598926 |
| `ls` 단독 | 0.603982 |
| `lgbm_t1` 단독 | 0.614009 |
| damped 단독 | 0.663402 |

**로컬 폴드로 가중을 고르는 행위는 이 문제에서 3회 연속 실패했다**
(`f.hp_below_noise_floor`; T13 Spearman −0.83, T21 블렌드 +0.021954, T26 블렌드 +0.021873).
따라서 이 실험은 **가중을 일절 적합하지 않는다.** 아래 고정 상수만 쓴다.

T1F 제출 가중 W_old = `persistence 0.00 / damped 0.35 / lgbm_t1 0.65` (상수, `select_t1f.py`).

## 작업 A — 고정가중 성분교체 (학습 0)

W_old 의 세 번째 성분만 바꾼다. **가중은 0.00/0.35/0.65 로 고정.** 격자탐색 금지.

| ID | 세 번째 성분 |
|---|---|
| S0 (대조군) | `lgbm_t1` |
| S1 | `lr` |
| S2 | `ls` |
| S3 | `(lr + ls) / 2` |
| S4 | `(lgbm_t1 + lr) / 2` |

저장된 조밀 OOF (`P3/preds/oof_dense_*`) 로 fold1·2·3·4 조밀 재가중 RMSE 를 낸다.
`[0, 30]` 클립, 클립행수 보고.

### 수락 기준 A — 결과 보기 전 고정

1. **(대조군)** S0 fold4 가 `0.611959` 와 `|델타| <= 1e-6`. 어긋나면 **중단하고 숫자만 보고한다**
   (W_old 재구성이 T1F 와 다르다는 뜻이다).
2. **(채택)** 어느 교체가 fold4 에서 `0.611959` 를 **0.005 이상** 개선하고 **동시에**
   `lr` 단독 `0.598926` 을 **0.003 이상** 개선해야 한다. 둘 중 하나라도 미달이면
   교체는 채택하지 않고 `lr` 단독이 유지된다.
3. fold4 는 어떤 선택·적합에도 쓰지 않는다 (가중이 상수이므로 적합 자체가 없다).

## 작업 B — lr 시드 분산 (코드만, 실행은 사람)

`f.log_ratio_target_wins` 의 `−0.013033` 이 시드 잡음 안인지 아무도 모른다.
**조밀 재가중 판정기의 시드 분산은 이 프로젝트에서 한 번도 측정된 적이 없다.**

`P3/src/train_target_transform.py` 에 `--seed` 인자를 추가한다 (기본 42, 현행 동작 불변).
시드는 LGBM `random_state`·`bagging_seed`·`feature_fraction_seed` 등 모델 난수 전부에 걸어라.
출력 npy 파일명에 시드를 붙인다: 시드 42 는 **현행 이름 그대로**
(`oof_dense_lr_p3_t26.npy`), 그 외는 `oof_dense_lr_p3_t26_s{seed}.npy`.

codex 는 `--seed 7 --max-folds 1` 스모크 1회로 인자가 먹는 것만 증명하고 멈춘다.
전체 실행 명령 2줄(시드 7, 시드 2026, `--max-folds 4 --n-jobs 6`)을 보고한다.

### 수락 기준 B — 결과 보기 전 고정

1. 시드 42 재실행이 기존 `oof_dense_lr_p3_t26.npy` 와 **비트 동일**해야 한다
   (`--seed 42` 가 현행 동작을 바꾸지 않는다). 스모크에서 fold1 배열로 확인하고 max 절대차를 보고한다.
2. (판정은 Opus 가 3시드 결과를 받은 뒤 한다) 3시드 fold4 RMSE 의 최대−최소가 `0.010` 이상이면
   `lr` 의 승리는 시드 잡음 안이며, 3시드 평균이 `0.611959` 를 `0.005` 이상 개선할 때만 유지한다.
