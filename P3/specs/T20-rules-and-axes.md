# T20 — 규정 원문 확인 + 신규 실험축 발굴 (읽기 전용)

## 목적

두 가지만 한다. **코드를 쓰지 마라. 파일을 만들지 마라. 읽고 보고만 한다.**

1. 배포된 대회 자료 원문에서 **외부 데이터 사용 가부**를 직접 확인한다 (추론 금지)
2. 아직 닫히지 않은 **신규 실험축 후보**를 열거한다

## 배경 — 이미 확정된 사실이다. 재조사하지 마라

- 로컬 개선 경로는 소진됐다. 닫힌 축: `a.calendar_features`, `a.station_lead_experts`,
  `a.equilibrium_relax`, `a.gated_blend`, `a.strict_forward_nested`
- 하이퍼파라미터·소폭 가중 변형은 후보가 아니다 (`f.hp_below_noise_floor`,
  folds1-3 평균순위와 봉인 fold4 순위 Spearman -0.83)
- 조밀 앙상블 풀은 사실상 3멤버뿐이다 (`f.pool_no_diversity`, LGBM 변형 6개 전부 rho>0.98)
- public LB 는 200사례 중 ~80 이하 무작위 부분집합과 모순 없다 (`f.public_small_random_subset`)
- 현행 제출 T1F = persistence 0.00 / damped 0.35 / lgbm 0.65, public RMSE 0.587165
- 설치된 패키지: `numpy`, `pandas`, `scipy`, `lightgbm`, `scikit-learn` 계열.
  **없는 것: `torch`, `xgboost`, `catboost`.** 새 의존성은 사용자 승인이 필요하다
- 하드웨어: 8코어 / RAM 31.5GB 를 3세션이 공유. 이 문제 몫은 `n_jobs<=2`, RAM 10GB
- **`pip install` 을 실행하지 마라.** 필요하면 필요하다고 적기만 하라

## 작업 1 — 규정 원문

`P3/` 트리와 `P3/P3_data/` 에서 대회가 배포한 규정·문제지·README 성격의 원문을 찾아 읽는다.
`P3/COMPETITION_RESEARCH.md`·`P3/DOMAIN_RESEARCH.md` 는 우리가 쓴 2차 문서이므로 근거가 아니다.
원문이 없으면 "원문 없음" 이라고 적어라. 추측으로 채우지 마라.

보고 형식 (표만):

| 항목 | 원문 인용 (파일:행, 한 줄) | 판정 |
|---|---|---|
| 외부 데이터 학습 사용 | | 명시 허용 / 명시 금지 / 언급 없음 |
| 사전학습 모델·가중치 사용 | | 명시 허용 / 명시 금지 / 언급 없음 |
| 제출 시 코드·가중치 요건 | | |
| 추론 입력 제약 원문 | | |
| 답안 제출 횟수 원문 | | |

인용은 **실제 파일에 있는 문자열만** 쓴다. 없으면 빈칸으로 두고 "언급 없음".

## 작업 2 — 신규 축 후보

위 닫힌 축과 **기제가 다른** 후보만 낸다. 각 후보를 아래 표 한 줄로.

| 축 이름 | 무엇을 바꾸나 (1줄) | 기존 3멤버와 잔차 상관이 낮을 이유 | 새 의존성 | 8코어 기준 예상 학습 시간 | 닫힌 축과 구별되는 지점 |
|---|---|---|---|---|---|

최소 8개, 최대 15개. 아래 방향을 **반드시 각각 1개 이상** 포함하되, 억지로 채우지 말고
불가능하면 그 줄에 "불가: <사유>" 를 적어라.

- 외부 데이터·사전학습 (작업 1 결과가 '명시 금지' 면 전부 "불가: 규정" 으로 적는다)
- 학습 **타깃 변환** (예: 잔차·비율·로그 등 — 구체적으로)
- 학습 **손실함수·목적함수** 변경
- 컨텍스트 289행의 **미사용 열** 활용 (현재 어떤 열이 덜 쓰이는지 코드에서 확인해 적어라)
- 시계열 구조 모델 (상태공간·스펙트럼 등, `torch` 없이)
- 다중 리드 **동시** 예측 구조 (현행이 무엇인지 코드에서 확인해 적어라)

## 금지

- 코드 작성·수정·실행 금지. 파일 생성 금지. 학습 금지. 제출물 생성 금지
