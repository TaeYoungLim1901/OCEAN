# T26 — 타깃 변환 3종 (비율 · 로그비율 · log1p+smearing)

**결론 문장 금지. 숫자와 표만 보고한다.** 산문 요약·권고·다음 단계 제안을 쓰지 마라.

## 배경 · 기준선(baseline) 숫자 — 재조사 금지, 그대로 쓴다

현행 학습 타깃은 **가법 delta** 다: `train.py:target_delta` 가 `y - hs0` 를 학습하고
`train_dense.py:116` 이 `hs0 + delta` 로 복원한다. 승법 오차 구조는 한 번도 시험 안 했다.

판정기는 **조밀 재가중** 하나만 쓴다 (public LB 로 검증됨, `f.lb_picks_dense_judge`).
씨닝 판정기는 부호가 반대다 — 쓰지 마라.

| 기준선 (조밀 재가중 봉인 fold4) | RMSE |
|---|---|
| 현행 T1F | 0.611959 |
| `lgbm_t1` (= A_base) 단독 | 0.614009 |
| damped 단독 | 0.663402 |
| persistence 단독 | 0.769115 |

이미 닫힌 것: 하이퍼파라미터 탐색은 판정기 잡음 바닥 아래다 (`f.hp_below_noise_floor`,
folds1-3 순위와 fold4 순위 Spearman −0.83). **이 실험에서 하이퍼파라미터를 건드리지 마라.**
LGBM 설정은 `lgbm_t1` 과 **완전히 동일**하게 두고 타깃 변환만 바꾼다.

조밀 풀은 사실상 3멤버뿐이고 LGBM 변형은 전부 ρ>0.98 이다 (`f.pool_no_diversity`).
비트리 멤버 2종(arx ρ=0.832 / wsswell ρ=0.759)은 상관 벽을 뚫었으나 fold4 블렌드는 미달이었다.

## 무엇을 만드는가

`P3/src/train_target_transform.py` 신규 1파일. `train_dense.py` 의 조밀 폴드 배정·
`forward_train_mask`·재가중 채점 경로를 **그대로 재사용**한다 (복사하지 말고 import).
피처는 현행 그대로. 새 피처 금지.

변형 3개. `eps = 0.1` 고정 상수.

| ID | 학습 타깃 | 역변환 |
|---|---|---|
| R | `y / (hs0 + eps)` | `pred * (hs0 + eps)` |
| LR | `log(y / (hs0 + eps))` | `exp(pred) * (hs0 + eps) * s` |
| LS | `log1p(y)` | `expm1(pred) * s` |

`s` = smearing 계수. **해당 폴드의 학습분할 잔차로만** 계산한다
(`s = mean(exp(residual))` 또는 log1p 계열이면 그에 대응하는 형태). 검증·봉인 폴드 자료로
`s` 를 계산하면 누수다. 폴드마다 `s` 값을 보고한다.

전부 `[0, 30]` 클립. 클립된 행 수를 보고한다.

## 수락 기준 — 결과 보기 전 고정 규칙

1. **(대조군)** 같은 코드 경로로 재생성한 `lgbm_t1` 조밀 재가중 fold4 가 `0.614009` 와
   `|델타| <= 0.002`. 어긋나면 채점경로 불일치이므로 **중단하고 숫자만 보고한다.**
2. **(단독 필수)** 각 변형 단독의 조밀 재가중 fold4 RMSE `<= 0.85`. 초과 변형은 블렌드에서 제외.
3. **(풀 채택)** folds1-3 에서 `lgbm_t1` 과의 잔차 Pearson 상관 `< 0.90` 이면
   결과와 무관하게 풀에 남긴다.
4. **(제출 채택)** 둘 중 하나를 만족해야 한다.
   - (a) 어느 변형 단독이 봉인 fold4 에서 `0.611959` 를 **0.005 이상** 개선
   - (b) 가중을 **folds1-3 에서만** 0.05 격자로 고른 블렌드(멤버: persistence·damped·lgbm_t1·
     통과한 변형들)가 봉인 fold4 에서 `0.611959` 를 **0.005 이상** 개선
   둘 다 미달이면 세 축을 전부 닫는다.
5. **fold4 는 어떤 선택·적합·smearing 에도 쓰지 않는다.**

## 실행 분담

codex 는 **fold1 만** 도는 스모크 실행으로 코드가 끝까지 도는 것을 증명하고 멈춘다
(`--max-folds 1`). 4폴드 전체 학습은 사람이 돌린다.

스모크에서 보고할 것: 각 변형 fold1 단독 조밀 재가중 RMSE, smearing 계수, 클립행수,
소요 초, 그리고 **4폴드 전체 실행 명령 1줄**.

`--n-jobs` 는 CLI 인자로 두고 기본값 2 로 한다.
