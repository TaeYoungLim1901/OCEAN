## 작업 — 두 가중, 네 판정기, fold 별 분해

가중 후보는 **정확히 2개**다. 다른 조합을 탐색하지 마라.

```
W_old = (persistence 0.00, damped 0.35, lgbm_t1 0.65)
W_new = (persistence 0.00, damped 0.65, lgbm_t1 0.35)
```

각각을 아래로 채점한다:

1. 조밀 **재가중**, fold1 / fold2 / fold3 / fold4 각각
2. 조밀 **비가중**, fold1 / fold2 / fold3 / fold4 각각
3. 조밀 재가중 folds1-4 통합
4. fold 별 ESS (T9 값 재사용 가능. 그대로 보고)

추가로 조밀 재가중 fold4 에서 세그먼트 분해(`lead`, `station`, `hs0bin`)를 `n` 과 함께
두 가중 모두에 대해 내고, 차이가 큰 순 5개를 보고하라.

## 수락 기준 (결과 보기 전 고정)

- 두 가중의 성분 합이 각각 `1.0 ± 1e-6`
- 조밀 재가중 fold4 에서 `W_old` 점수가 T9 의 `0.611959` 와 `|델타| <= 0.001`.
  벗어나면 하네스 불일치이므로 **점수 해석 없이 그 사실을 보고하라** (대조군)
- fold 별 ESS 가 4폴드 모두 `>= 300`
- 산출 `P3/cache/p3_t11/report.json` 에 위 숫자 전부
