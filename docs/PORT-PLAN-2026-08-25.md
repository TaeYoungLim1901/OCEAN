루트(`scripts/`·`.claude/`·`AGENTS.md`) 단계는 P3 세션 소유. `P{n}/src/` 단계는 각 세션 병렬.

| 순서 | 항목 | 소유 | 수락 기준 | 롤백 |

| **3** | **P1 forward-only purge 수정 + 오염 cache 격리** | P1 | `python P1/src/bugcheck.py C1` → `future_rows=0 mask_differences=0` | `features.py` hunk revert |

| 5a·5b·5c | 각 문제 `bugcheck all` FAIL 원인 제거. **검사 완화 금지** | 각 트리 | `python P{n}/src/bugcheck.py all` exit 0 | 원인 수정 revert |
| 6a·6b·6c | B `--pred` 필수 (argparse + 함수 API 양쪽) | 각 트리 | `python P{n}/src/submission_tools.py selftest` exit 0 | hunk revert |
