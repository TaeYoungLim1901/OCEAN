# T22 — 제출 후보의 예상 public RMSE·점수를 내는 도구

## 왜 (읽고 넘어가라, 재조사 금지)

숨은 정답이 없어 public RMSE 를 로컬에서 계산할 수 없다. 그런데 지금까지 3회 연속으로
제출 전에 public 을 정확히 예측했다. 근거는 **항등식** 이다.

기준 제출 `B` 의 public MSE 가 `M0` 로 알려져 있을 때, 후보 `C = B + w·d` 에 대해

```
MSE(w) = M0 + w²·E[d²] − 2w·E[d·e]
```

`E[d²]` 는 배열에서 계산되고, `E[d·e]` 는 **같은 방향 `d` 의 public 실측이 2개 이상 있으면**
역산된다. 실적:

| 후보 | 예측 | 실측 |
|---|---:|---:|
| E014 (w=-1) | 0.523935 | 0.523888 |
| E017 (w=-2.5) | 0.522635 | 0.522638 |

점수 환산도 확정됐다. public 3점 `(0.537099, 26.594071)` `(0.523888, 26.759837)`
`(0.522638, 26.775526)` 에서 역산했고 세 점 모두 잔차 ±0.0001 안이다.

```
점수 = 33.3335 − 12.54789 × RMSE
```

원장은 `P2/src/submission_tools.py public list` 로 읽는다.
저장 위치는 `P2/experiments/public_scores.csv` 다.

## 만들 것

`P2/src/predict_public.py <후보csv> [--base <기준csv>]` 신규 파일 1개.

`--base` 를 주지 않으면 원장에서 **public 최소인 CSV** 를 기준으로 잡는다.

### 계산 절차

1. 후보와 기준의 `temp` 차 `d` 를 26,061행에 대해 계산한다. 키 순서가 다르면 **멈추고 보고**한다
2. 변경 행 수 `m`, `E[d²]` (전체 26,061행 기준), `max|d|`, `mean d` 를 낸다
3. **정확 예측이 가능한가** 판정한다. 원장에 `d` 와 **평행한** 방향의 실측이 2개 이상 있으면
   가능하다. 판정 방법: 원장의 각 CSV 쌍 `(P, Q)` 에 대해 `Q − P` 가 `d` 와 평행한지
   (상관계수 1 또는 -1 에 1e-9 이내로 일치, 그리고 0 이 아닌 행 집합이 같은지) 본다
   - 평행한 방향이 있으면 그 방향의 public 실측점들로 `E[d²]_public`·`E[d·e]_public` 을 역산해
     **점 예측**을 낸다. 실측점이 3개 이상이면 항등식이 과결정되므로 잔차도 함께 보고한다
   - 없으면 점 예측을 내지 마라. 아래 4번 구간만 낸다
4. 항상 **구간**을 낸다. Cauchy-Schwarz 로
   `|E[d·e]| ≤ sqrt(E[d²]·M0)` 이므로
   `MSE ∈ [M0 + E[d²] − 2·sqrt(E[d²]·M0),  M0 + E[d²] + 2·sqrt(E[d²]·M0)]`
   RMSE 와 점수로 환산해 함께 출력한다
5. **측정 가능성**을 판정한다. 리더보드는 6자리라 `|ΔRMSE| < 0.000002` 면 구분 불가다.
   구간 폭이 이보다 좁으면 `측정불가` 를 출력한다 — 제출 슬롯을 쓸 가치가 없다는 뜻이다

### 출력 형식

키=값 한 줄씩. 표나 산문 금지. 최소한 아래 항목:

```
base=<경로> base_public=<값> base_score=<값>
changed_rows=<m> E[d2]=<값> max|d|=<값> mean_d=<값>
exact=<True|False> [parallel_dir=<원장CSV들> w=<값> E[d.e]=<값> residual=<값>]
point_rmse=<값> point_score=<값>          # exact=True 일 때만
range_rmse=[<하한>,<상한>] range_score=[<하한>,<상한>]
measurable=<True|False>
```

## 검증 — 직접 실행하고 숫자를 보고해라

이미 정답을 아는 3건으로 자기검증한다.

```
python P2/src/predict_public.py P2/subs/E014_antistack_w-1.csv --base P2/subs/E009_maskaug_diff.csv
python P2/src/predict_public.py P2/subs/E017_antistack_w-2.5.csv --base P2/subs/E009_maskaug_diff.csv
python P2/src/predict_public.py P2/subs/E010_stackregime_complete.csv --base P2/subs/E009_maskaug_diff.csv
```

E014·E017 은 원장에 실측이 있으므로 `exact=True` 가 나와야 하고 점 예측이 실측과
**0.00005 이내**여야 한다. 세 명령의 출력을 그대로 보고에 넣어라.
