## 1. 배경과 편향 고지 (그대로 로그에 기록할 것)

E005 는 4-hold 균등 평균 규칙에서 **기각**됐다. 그러나 `missing_public` 세그먼트 방향이 hold 별로 갈렸다:

| hold | 계절 | E002(=E004가 결측행에 쓰는 값) | maskaug | Δ |
|---|---|---|---|---|
| 2024_sepoct | Sep-Oct (test 와 동일) | 1.135442 | 1.000900 | **-0.134542** |
| 2025_julaug | Jul-Aug (test 결측 패턴 이식) | 1.282815 | 1.207117 | **-0.075698** |
| 2024_julaug | Jul-Aug | 1.215896 | 1.282816 | +0.066920 |
| 2025_mayjun | May-Jun | 1.814061 | 1.871968 | +0.057907 |

실제 test 는 **2025-09-01~10-31 전체가 Sep-Oct** 이다. Jul-Aug·May-Jun hold 는 test 에 존재하지
않는 계절로의 전이를 재는 것이다. **이 계절 정합 관점은 E005 결과를 본 뒤에 세운 사후 프레임이다.**
그래서 기존 4-hold 로 재판정하지 않고, **계절 정합 holdout 을 새로 만들어 독립 증거로 다시 잰다.**

## 3. 계절 정합 holdout 구성

2024년(=정답이 공개된 유일한 연도) 안에서 **Sep-Oct 를 포함하는 연속 2개월 창** 4개를 만든다.
각 창은 기존 절차와 동일하게 층 2·3·4 를 동시에 가리고 test 공개층 결측 패턴을 이식한다.

**창 길이는 test 창(2025-09-01~10-31, 시점 8784개)과 정확히 같아야 한다.** 기존 pseudo-mask
함수가 동일 길이만 허용한다(2026-08-13 E006 1차 시도에서 확인). 길이를 바꾸지 말고 창을 이동시켜라.

권장 창(데이터 범위 밖이면 그 창을 버리고 실제 사용 창을 표로 보고한다):

- `S1` 2024-09-01~10-31 (기존 `2024_sepoct` 와 동일)
- `S2` 2024-08-16~10-15
- `S3` 2024-09-16~11-15
- `S4` 2024-10-01~11-30

`S3`·`S4` 가 데이터 끝을 넘으면 대신 시작을 앞으로 당긴 창(`2024-08-01~09-30`, `2024-07-16~09-14`)을
같은 길이로 만들어 채운다. 최소 2개 창이 확보되지 않으면 학습하지 말고 그 사실만 보고하라.

조건: 각 창의 truth 행이 **20000 이상**이어야 채택한다. 미달 창은 버리고 그 사실을 보고한다.
창끼리 겹치는 것은 허용하되, 겹침 비율을 표4에 보고한다(증거의 독립성이 아니라 상관을 알기 위함).

각 창마다 그 창을 제외한 구간으로 `maskaug` 를 **새로 학습**한다. 창 정보를 학습에 흘리지 마라.

## 4. 최종 예측 조립 (채택 시)

```
pred[i] = maskaug_test[i]              if missing_public_flag[i]
          E004_gate_robust_blend[i]    otherwise
```

`P2/preds/test_maskaug_E005.npy` 는 이미 존재하므로 test 예측을 다시 학습하지 마라. 조립만 한다.
완전 공개 행은 `P2/preds/test_gate_robust_blend_E004.npy` 와 **비트 단위로 같아야** 한다.

## 4.1 기준선 숫자

기준선은 E004 조립이다: 4-hold 평균 `1.089067`, 2025_julaug 전체 `1.271631`,
2024_sepoct 전체 `0.495506`, 결측행 `missing_public` 은 E002 값(2024_sepoct `1.135442`,
2025_julaug `1.282815`)을 그대로 쓴다. 재계산해 불일치하면 그 사실을 표에 적어라.

## 5. 수락 기준 — 사전등록 판정 규칙 (결과 보기 전 확정. 사후 변경 금지)

판정 증거는 **§3 의 계절 정합 창들** 뿐이다. Jul-Aug·May-Jun hold 는 참고로만 표에 싣는다.

1. 채택된 계절 정합 창 중 **≥ 3/4 에서** `missing_public` RMSE 가 E002 대비 **개선**
2. 계절 정합 창들의 `missing_public` **평균 개선 ≥ 0.020**
3. 어떤 계절 정합 창에서도 `missing_public` 악화 **≤ 0.010**
4. 각 계절 정합 창의 **전체 RMSE** 가 E004 조립 대비 악화 **없음**(≤ 0.000)
5. 완전 공개 행이 E004 와 **비트 단위 동일**

전부 만족하면 채택, 아니면 **기각**하고 E004 를 유지한다. 채택 창이 2개 이하로 줄면
증거 부족으로 **기각**한다. 규칙 완화 금지.
