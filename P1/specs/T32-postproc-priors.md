# T32 — exp020: exp016 위에 지속시간 사전 후처리. 학습 없음

## 목적

문제지가 주입 지속시간을 명시했고 train 라벨 run 263개로 검증됐다 (`r.duration_prior`):
길이 1(spike) 101개, **길이 2~11 정확히 0개**, 길이 12 이상 162개, **최대 519행**.

T25 가 exp010 원시 확률에서 잰 예측 run 정밀도:

| 길이 버킷 | n_rows | 정밀도 |
|---|---|---|
| 1 | 71 | 0.521127 |
| **2–11** | 112 | **0.205357** |
| 12–47 | 667 | 0.449775 |
| 48–119 | 1,938 | 0.885965 |
| 120–519 | 7,926 | 0.893894 |
| **520+** | 1,240 | **0.387097** |

두 버킷이 사전을 위반한다. 2~11 은 존재할 수 없고, 520+ 도 존재할 수 없다.
T25 는 2~11 만 다뤘다. **이번엔 520+ 를 자르고, 기준을 exp016(현재 최고)으로 옮긴다.**

## 배경 — 이미 검증된 사실. 재조사·재측정 금지

- 현재 최고 제출 exp016 public F1 **0.776056** (27.381306점). 원시 확률 `P1/cache/exp016_raw_test.npy`,
  설정 `t_high 0.737` + `hole 48`, 양성 5070 (2.9998%). **기준선이자 이 사양의 출발점이다.**
- inner OOF 로 후처리를 고르지 마라 (`f.inner_delta_no_transfer`). 이 사양의 규칙은 전부
  **문제지 규격에서 나온 사전**이며 격자 탐색이 아니다.
- T25 구현은 `P1/src/t25_runlength.py` 에 있다. **재사용해라.**
- 길이 1 run 은 spike 다. **절대 삭제하지 마라** (T14 에서 spike recall 0.686→0.059 붕괴).
- exp016 은 inner OOF 가 없다 (전체 train 단일 모델만 학습했다). 따라서 exp016 기준 정밀도 측정은
  불가능하다. **측정은 exp005 OOF 로 하고, 규칙 적용은 exp016 test 확률에 한다.** 이 사실을 표에 적어라.
- `numpy`·`pandas` 설치됨. **`pip install` 이 필요하면 설치하지 말고 멈추고 보고해라.**

## 하지 말 것

- 학습 금지. 임계 재조정 금지 (`t_high 0.737` 고정). 새 feature 금지.
- 새 파일은 `P1/src/t32_postproc.py` 하나. 기존 파일 수정 금지. `SEED=42`.

## 규칙

순서 고정: 임계 0.737 → `hole=48` 채움 → 아래 사전 규칙.

- **R1 (2~11 삭제)**: 길이 2~11 인 run 을 0 으로 만든다. 길이 1 은 보존한다.
- **R2 (519 캡)**: 길이 520 이상인 run 은 **원시 확률이 낮은 쪽 끝부터 잘라** 519행으로 줄인다.
  잘라낼 위치는 결정론적이어야 한다 (동점이면 뒤쪽 행부터 자른다).
