# 문제 1. 종합해양과학기지 관측 수온 자동 품질관리 ( https://oceanaidata.org/app/problems/5 )
1-1. 배경
해양 관측 기지의 센서는 장기간 해수에 노출된 상태로 운영되므로 여러 원인으로 비정상 신호를 냅니다. 센서 거치 수심의 변동, 커넥터 접촉 불량, 전원 계통의 불안정, 교정 주기 경과에 따른 편차 누적이 대표적입니다. 이러한 이상은 하나씩 순차적으로 나타나기보다 여러 원인이 같은 시기에 겹쳐 복합적으로 발현되는 경우가 많습니다.

이 과제의 성격을 먼저 확인하십시오.
본 과제는 실제 품질관리의 전 과정을 재현하는 것이 아니라, 정상으로 판정된 관측에 대표적인 센서 이상을 합성하여 주입하고 그 자동 탐지 능력을 평가하는 교육용 문제입니다. 주입 비율과 지속시간 범위는 실제 장애 통계가 아니라 대회 운영을 위해 설정한 값입니다.
한편 생물 부착(biofouling)은 주로 전도도 센서의 교정 상수를 변화시켜 염분 값 자체를 틀어지게 만들며, 수온 센서에서는 응답 지연으로 나타날 뿐 평형값은 대체로 보존됩니다. 따라서 본 과제가 판정 대상으로 삼는 수온 이상의 직접 원인으로는 다루지 않습니다.

1-2. 과제
배포된 수온 시계열의 각 시점에 대하여 그 값이 센서 이상에 해당하는지 판정하십시오.

판정 대상: 수온(temp). 염분(psal)과 설치 수심(depth)은 참고 변수로 제공합니다.
이상은 원자료의 품질 플래그가 1(good_data)인 구간에만 주입되어 있습니다.
전체 유효 관측의 약 4%가 이상 구간이며, 이 중 일부는 두 가지 이상의 유형이 같은 시기에 중첩되어 있습니다.
1-3. 주입된 이상의 유형
유형	지속시간	양상
spike	10분	단일 시점의 급격한 이탈
noise	3~58.8시간	분산이 비정상적으로 커진 구간
flatline	2~47.2시간	값이 변하지 않고 고정된 구간
offset	8~86.5시간	일정한 크기만큼 치우친 구간
drift	9~86.5시간	시간에 따라 편차가 선형으로 누적되는 구간
1-4. 접근에 참고할 사항
같은 기지의 층간 수온 관계는 유용한 단서이지만 항상 유효하지는 않습니다. 조석 혼합이 지배하는 시기·기지에서는 층간 상관이 높아 단서가 되지만, 수온약층이 발달한 시기에는 약층 상하의 상관이 소실되어 정상적인 성층 구조를 이상으로 오탐할 수 있습니다. 계절과 성층 상태를 함께 고려하십시오.
계절 성층과 내부파의 통과로 한 층만 단시간에 급변하는 일이 실제로 발생합니다. 판정에 사용하는 시간창의 길이를 계절 조건과 함께 조정하는 것이 유리합니다.
기지별 수온 변동의 크기와 성격이 다르므로, 정점·층 단위로 표준화한 지표가 전 구간 공통 임계값보다 안정적입니다.
유형별로 드러나는 통계량이 다릅니다. spike는 1차 차분, flatline은 연속 동일값의 길이, drift는 장기 이동평균과의 편차가 각각 민감합니다.
1-5. 배포 데이터
파일	내용
train.csv	2024~2025년 관측 + 정답 라벨 (776,706행)
test.csv	2026년 관측, 라벨 비공개 (169,011행)
sample_submission.csv	제출 양식
baseline_rule.csv	규칙 기반 기준값 예측
P2 정답 보호를 위해 S-ORS 2025년 9~10월 layer 2·3·4는 P1 학습에서 제외했습니다. 정점·층별 실제 운영기간과 결측률은 서로 다르며 G-ORS 2026년 depth는 전부 결측이고 I-ORS 2026년 layer 3은 미운영입니다.
1-6. 제출 형식
station,year,layer,time,label,anomaly_type
S-ORS,2026,2,2026-05-14T03:20:00+09:00,1,spike
S-ORS,2026,2,2026-05-14T03:30:00+09:00,0,
label: 이상이면 1, 정상이면 0 (필수)
anomaly_type: 유형 문자열 (선택). 순위에는 반영하지 않으며 본선 심사의 참고자료로만 활용합니다.
평가 지표는 이상 구간(label=1)에 대한 F1 점수입니다.

주최측 사전 검증 결과
규칙 기반 전체 평가 기준 F1은 0.548255입니다. 종합점수 계산에서는 각 리더보드 분할에서 같은 베이스라인 제출을 다시 채점한 값을 사용합니다.
