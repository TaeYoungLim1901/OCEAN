# codex 위임

**★ 코드 작업은 전부 여기로 간다.** Opus 는 사양을 쓰고 숫자를 읽는다 (`AGENTS.md` §0).
직접 편집이 허용되는 예외는 한 줄 게이트 명령·문서 쓰기·긴 학습 실행 3개뿐이다.

**호출 1회 오버헤드 ≈ 8.7k 토큰.** 잘게 부르지 마라. 관련 작업은 `P{n}/specs/*.md` 하나로 묶는다.
템플릿: `P{n}/specs/_TEMPLATE.md` 를 복사해서 채운다.

```bash
scripts\cx.cmd P3/specs/T1-name.md      # luna xhigh, 파일 수정 허용
scripts\cx.cmd -r P3/specs/q.md         # 읽기 전용
```

2026-08-13 현재 Git Bash 5.3.15, Codex CLI 0.147.0, ChatGPT 로그인과 Luna xhigh 호출을 검증했다.

`cx.sh` 가 호출 직전에 `preflight.py spec` 을 돌린다. STOP 이면 codex 를 부르지 않는다.

## 1. 사양 골격

```markdown
# 작업 지시: T{n} — {제목}

루트 `AGENTS.md`와, 존재하면 `P{n}/AGENTS.md`를 준수. python 은 시스템 `python` 을 쓴다.
`pip install` 이 필요하면 **멈추고 보고하라.** 원본 데이터와 `src/metric.py` 는 읽기 전용.

## 배경 — 이미 검증된 사실 (재조사 금지)
{`g.py show` 로 꺼낸 fact 노드. codex 가 다시 측정하느라 토큰 태우는 걸 막는다}

## 기준선
{실험ID = 정확한 숫자. 어느 스크립트의 숫자인지 함께}
{"지정된 것 외에는 바꾸지 마라"}

## 실험 N — {이름}
### 근거 / ### 사양 / ### 수락 기준

## 금지
- 가설을 섞지 마라. 각 실험은 기준선에서 한 가지만 다르다
- 하이퍼파라미터 튜닝 금지 (별도 지시 시에만)
- 결론 문장 금지. 숫자와 표만

## 완료 보고 형식
{낼 숫자를 한 줄씩. 코드 전문 붙여넣기 금지}
```

## 2. 함정 — 실제로 실행 1회씩 날린 것들

- **수락 기준은 절대 하한으로.** "내 참고치와 일치" 를 요구하면 전처리 차이로 소수 셋째 자리가
  달라 통과 못 한다. `corr >= 0.99` 처럼 써라
- **대조군을 요구하라.** 새 학습 스크립트에는 반드시 기존 기준선을 재현하는 모드를 넣고
  그 숫자를 먼저 출력하게 한다. 없으면 결과가 가설 때문인지 하네스 때문인지 모른다
- **보고할 숫자를 항목별로 나열하라.** "MAE 비교" 로 쓰면 값이 누락된다
- **출력 디렉터리가 없으면 실행이 죽는다.** `preflight spec` 이 잡지만 사양에도 `mkdir` 지시를 넣어라
- **학습 실행은 위임 금지.** 샌드박스 시간 제한. 코드만 만들게 하고 학습은 사람이 돌린다
- **후처리·상수를 다루면 전반/후반 분할의 실현 이득을 요구하라.** 전체fit 이득은 항상 부풀려져 있다

## 3. 결과가 나왔을 때 먼저 의심할 것

점수를 해석하기 **전에** 확인한다. 하나라도 걸리면 결과는 무효다.

- 스윕 조합끼리 값이 소수 6자리까지 같은가 → 파라미터가 반영 안 된 버그
- 서로 다른 실험이 같은 값을 내는가 → 우연일 확률 0
- `best_iteration` 이 1 이거나 상한에 붙었는가 → 학습 실패 / 조기종료 미작동
- 기준선 재현 대조군 숫자가 보고에 있는가 → 없으면 요구하라
- LightGBM 은 `bagging_fraction`·`feature_fraction` 이 없으면 시드에 무관하게 결정론적이다.
  시드 앙상블을 시키려면 샘플링을 켜라

## 4. 로그 읽기 — 전문 읽지 마라

```bash
tail -20 P3/experiments/logs/codex_T{n}.log
```

## 5. 결과 판정 후

1. `P{n}/experiments/log.md` 에 1행. **기각도 반드시, 이유와 함께**
2. 닫은 축은 `g.py close <축> --evidence "<숫자>"`
3. 로컬 이득을 리더보드 예상점수로 환산하지 마라. Local/LB 를 분리 기록한다

## 6. 병렬

codex 2개 동시 실행 가능. 단 **같은 파일을 건드리는 사양은 동시에 돌리지 마라.**
문제 트리가 다르면 안전하다. 백그라운드로 돌리고 폴링하지 마라.

codex 쿼터가 막히면 `gemini`. 사양 규약은 동일. `--approval-mode plan` 이 읽기 전용이다.
