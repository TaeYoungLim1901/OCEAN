# 채점 반복 루프

한 사이클 = **가설 1개 → 변경 1개 → 채점 → 판정 → 기록.**
두 개 바꾸면 어느 쪽이 효과인지 영원히 모른다.

**★ 변경·채점 실행은 codex luna xhigh 가 한다** (`AGENTS.md` §0). Opus 는 가설을 세우고
사양을 쓰고 보고된 숫자로 판정한다. 게이트 한 줄 명령만 직접 돌린다.

## 1. 착수 전

```bash
python scripts/g.py --p P3 check "<가설 키워드>"     # 닫힌 축이면 exit 1, 멈춘다
```

한 줄로 적어라: *「이 실험은 [실패모드]를 고치고, 결과와 무관하게 [예측파일]을 앙상블 풀에 남긴다」*
둘 다 못 쓰면 그 실험은 하지 마라. **판정 규칙은 결과를 보기 전에 기록한다.**

## 2. 채점

```bash
python P3/src/metric.py --pred <pred.csv> --true <true.csv> --by lead station --baseline <직전 RMSE 숫자>
```

`--by` 는 필수다. 전체 점수 하나만 보는 실험은 시작하지 마라 — 평균이 신호를 지운다.
BARAM 에서 200회를 3그룹 평균 위에서 돌렸고, 분해해보니 한 그룹이 격차의 77% 였다.

분해 축: `lead`(+18/+24h가 지속성 기준 SSE의 약 47.5%) · `station` · `hs0bin`(t0 파고 구간).

## 3. 진단 → 다음 수

| 신호 | 해석 | 다음 수 |
|---|---|---|
| 평균편차가 리드에 따라 커짐 | 사례 선정 편향(상위꼬리)에 의한 평균회귀 | 리드별 수축계수 적합 (`a.lead_shrinkage`). 가장 싸다 |
| 긴 리드만 나쁨 | 원격 너울 도착을 못 본다 (`p.swell_blind`) | 물리적 하한. 수축·기후값 혼합으로만 완화 |
| 한 정점만 나쁨 | 기상 데이터 커버리지 차이(`f.atmos_gap_is`) | 정점 pooled + 지시자 |
| t0 파고 큰 구간만 나쁨 | 감쇠 곡률을 못 잡음 | `a.equilibrium_relax`, `a.windsea_swell_split` |
| 로컬 이득이 유난히 큼 | 수준·스케일 축일 가능성 | 로컬은 낙관적이다. 리더보드 예산으로 판정 |

표에 없는 신호가 보이면 멈추고 사람에게 보고한다. 임의로 새 가설을 만들지 마라.

## 4. 제출 전

```bash
python scripts/preflight.py sub P3/subs/<exp>.csv --index P3/P3_data/test_index.csv \
    --base P3/P3_data/baseline_persistence.csv
```

`판정: OK` 가 아니면 던지지 마라. **하루 1회 제한**이라 한 장이 하루다.
`dist=mean|Δ|` 가 0 이면 기준과 같은 파일이다 — 슬롯 낭비.

## 5. 기록

```
| 실험ID | 날짜 | 가설 | 변경점 | Local(통합/리드별) | LB | 판단 |
```

`P3/experiments/log.md` 에 1행. **기각도 반드시.** 예측은 항상 남긴다:
`P3/preds/oof_{model}_{ver}.npy`, `P3/preds/test_{model}_{ver}.npy`.
진 실험의 예측이 나중에 앙상블에서 이긴다 — BARAM 상승분 100% 가 재조합이었다.

## 6. 절대 금지

- ❌ 로컬 통합 RMSE 를 공식 0.769455 와 직접 비교 (표본·기간이 다르다. **델타만**)
- ❌ 리더보드 추종 튜닝. 같은 Public 66사례의 여러 제출은 독립 표본이 아니다
- ❌ 같은 홀드아웃에서 다수 후보를 고른 결과를 절대 성능 추정에 사용
- ❌ `src/metric.py` 에 편한 기본값 추가
- ❌ 다른 test `case_id`의 행을 피처·정규화·예측에 사용 (하드 제약)
